# flow 记账 · 需求分析（MVP）

> 版本：v0.1（2026-10-25）  
> 状态：已确认并实现（2026-10-25）  
> 目标：在现有 flow 里加一个**只记支出**、足够简单的记账模块：分类、内容、金额、周报、月报。

---

## 1. 背景与目标

flow 现在有 Tasks、Habits、Settings。记账是第三个独立模块，和待办/习惯没有数据关系，但共用导航、主题、语言和本地存储。

第一版目标：

1. 快速记一笔支出：金额、分类、内容、日期。
2. 分类尽量全，覆盖衣食住行、通讯、API/开发、学习等，并支持自定义分类。
3. 按天查看流水，能编辑、删除。
4. 周报、月报：总额、笔数、分类占比、趋势。
5. 中英文、浅色/深色、本地持久化。

第一版不做：

- 收入 / 转账 / 借贷
- 多账户、支付方式、银行卡
- 预算、超支提醒
- 周期性账单
- 多币种、汇率
- 小票/图片附件
- 账单导入导出
- 分类图标、颜色、排序
- 报销、分摊、AA
- 云同步 / 账号

| 场景 | 用户动作 | 期望 |
|---|---|---|
| 中午吃饭 | 记一笔 ¥35，分类“午餐”，内容“公司楼下” | 立刻出现在今天的流水里 |

## 4. 核心概念与规则

### 4.1 概念

- **支出（Expense）**：一笔花钱记录，包含分类、内容、金额、日期。
- **分类（Category）**：支出归属，例如“午餐”“房租”“API 调用”。
- **分类组（Group）**：分类的一级归类，例如“餐饮”“居住”“开发 / API”。
- **流水（Records）**：按时间排列的支出列表。
- **周报 / 月报**：按自然周 / 自然月汇总的统计。
- 记账与待办、习惯完全独立，不互相影响统计。

### 4.2 金额

- 只记支出，金额必须大于 0。
- 单笔上限：`9,999,999.99`。
- 最多两位小数。
- 内部用**整数分**存储（`amountCents`），避免浮点误差；展示时除以 100。
- 币种固定为人民币 `¥`（第一版不支持多币种）。
- 显示格式：`¥1,234.50`，按当前语言做千分位；英文也用 `¥`。
- 输入：数字键盘，允许小数点；输入超过两位小数时不允许继续输入，或保存时提示。

### 4.3 内容

- 必填，1–80 字。
- 例如“公司楼下午饭”“OpenAI 额度”“地铁通勤”。
- 允许重复内容，不做唯一性校验。

### 4.4 日期

- 必填，默认今天。
- 不允许未来日期。
- 可以补记过去日期；不限制多久以前。
- 日期按本地日历日 `YYYY-MM-DD` 存储，不存 UTC 时间戳。
- 编辑时可以改日期。

### 4.5 分类

- 预设分类不可删除、不可重命名。
- 自定义分类可新增、删除；名称 1–20 字；重名（不区分大小写）不允许。
- 自定义分类被删除时，如果已有支出，二次确认后把这些支出迁移到“杂项”，总额不变。
- 自定义分类归入 `Custom / 自定义` 组。
- 新增支出时必须选择分类。
- 分类被删除后，历史支出仍需能显示；预设分类不可删除；自定义分类删除时迁移到“杂项”。
- 报表按分类聚合；自定义分类和预设分类同等对待。

### 4.6 删除

- 流水支持左滑删除，Toast 撤销。
- 编辑弹层不提供删除，避免误触。
- 删除后总额、分类占比、趋势立即更新。

## 6. 信息架构与导航

### 6.1 导航

手机底部导航从 3 个变 4 个：

`Tasks / Habits / Money / Settings`

- 手机：4 等分，标签 10–11px。
- 桌面：左侧栏加 `Money`。
- 记账页保留底部导航。
- 设置页 Data 汇总增加支出笔数，例如 `2 tasks · 4 habits · 18 expenses`。

### 6.2 路由

| 路由 | 页面 |
|---|---|
| `#/money` | 记账 · 流水 |
| `#/money/week` | 记账 · 周报 |
| `#/money/month` | 记账 · 月报 |
| `#/tasks` | 待办 |
| `#/habits` | 习惯 |
| `#/settings` | 设置 |

- Money tab 在流水、周报、月报三个页面都保持选中。
- 刷新、浏览器后退都保持当前页面。

### 6.3 记账页结构

顶部：

- 标题 `Money` / `记账`
- 副标题：已记录笔数，例如 `8 expenses recorded` / `已记录 8 笔支出`
- 单一分段标签：`Records / 流水`、`Weekly / 周报`、`Monthly / 月报`
- 不叠加第二组周期选择器；周期切换直接由主标签完成
- 右上角圆形 `+` 新增支出

#### 流水

- 月份选择：`2026年10月`，左右切换，`本月` 快捷
- 汇总卡：本月总额、笔数
- 按天分组：
  - 日期标题：`今天 / 昨天 / 10月24日 周五`
  - 当天小计
  - 支出行
- 空状态：本月还没有支出 + 记一笔
- 新增支出：右上角 `+` 或空状态按钮（不再使用悬浮 FAB）

支出行：

```
公司楼下
午餐                              ¥35.00
```

- 左侧：内容为主，分类为辅助信息
- 右侧：金额，等宽数字
- 点击行编辑；左滑删除
- 不显示正负号，金额统一为正数支出

#### 报表

- 周期切换由顶部 `Weekly / Monthly` 主标签完成，不再有第二组分段控件
- 期间导航：上一周/下一周、上一月/下一月、`本周`/`本月`
- 汇总：
  - 总额
  - 笔数
  - 日均（周报也用日均，按周期内天数算）
- 趋势：
  - 周报：7 根柱子，周一到周日
  - 月报：按 7 天聚合为 W1–W5，避免 31 根细柱
  - 点击/触摸柱子显示日期范围和金额
- 分类占比：
  - 按金额降序
  - 前 8 个分类 + “其他分类”聚合
  - 每行：分类名、金额、百分比、横条
- 空状态：这个周期还没有支出
- 不做饼图，统一用横向条形图和柱状趋势，和现有设计语言一致

## 7. 页面需求

### 7.1 新增 / 编辑支出

底部弹层，从上到下：

1. **金额**
   - 大号输入，前缀 `¥`
   - 数字键盘，最多两位小数
   - placeholder `0.00`
2. **分类**
   - 一行按钮，显示当前分类；未选时显示 `选择分类`
   - 点击打开分类选择器
3. **内容**
   - 单行/多行输入，placeholder `花在什么地方？` / `What was this for?`
   - 最多 80 字
4. **日期**
   - 默认今天
   - 提供 Today / Yesterday 快捷按钮
   - 点击打开日期选择器，不能选未来
   - 复用现有自绘日期选择器
5. **保存**
   - 新增：`记一笔` / `Add expense`
   - 编辑：`保存修改` / `Save changes`

校验：

- 金额为空 / 0 / 超过上限 / 超过两位小数 → 错误
- 未选分类 → 错误
- 内容为空 → 错误
- 日期为空或未来 → 错误
- 保存失败时聚焦对应字段

### 7.2 编辑与删除

- 点击流水行打开编辑弹层，字段回填。
- 左滑删除，Toast `已删除` + `撤销`，5 秒。
- 编辑保存后，按新日期归组，报表即时更新。
- 删除最后一笔时，显示当月空状态。

### 7.3 分类选择器

- 搜索框：输入中文或英文即时过滤。
- 新建分类：
  - 输入名称，1–20 字
  - 重复名称（不区分大小写）提示
  - 保存后自动选中并关闭新建输入
- 分类列表：
  - 组标题 + 分类行
  - 选中行打勾
  - 自定义分类在 `自定义` 组，置顶
  - 自定义分类右侧提供删除入口；已使用时确认后把支出迁移到“杂项”
- 分类选择器是二级弹层，盖在支出弹层上方，关闭后回到支出弹层。
- 顶部展示最近使用过的 4 个分类；搜索时隐藏最近分组，避免重复。

### 7.4 空状态 / 异常

| 状态 | 表现 |
|---|---|
| 本月没有支出 | 空状态 + 记一笔按钮 |
| 周报/月报没有支出 | 空状态 + 提示去记一笔 |
| 分类不存在（数据异常） | 显示 `未分类`，不崩溃 |
| 金额数据异常 | 忽略该条，或按 0 处理并记录 |
| 本地数据损坏 | 回退空数组，页面可用 |

## 8. 数据模型

### 8.1 类型

```ts
type ExpenseCategoryGroup =
  | 'food'
  | 'clothing'
  | 'housing'
  | 'transport'
  | 'communication'
  | 'development'
  | 'learning'
  | 'entertainment'
  | 'health'
  | 'social'
  | 'other'
  | 'custom'

interface Expense {
  id: string
  categoryId: string
  content: string
  amountCents: number      // 整数分，> 0
  date: string             // YYYY-MM-DD，本地日期
  createdAt: number
  updatedAt: number
}

interface CustomCategory {
  id: string
  name: string
  createdAt: number
}
```

预设分类写在代码里，不落库：

```ts
interface PresetCategory {
  id: string
  group: ExpenseCategoryGroup
  name: { en: string; zh: string }
}
```

### 8.2 存储

| Key | 内容 |
|---|---|
| `flow.expenses.v1` | `Expense[]` |
| `flow.customExpenseCategories.v1` | `CustomCategory[]` |

- 与待办、习惯、设置完全独立。
- 金额只存整数分。
- 日期只存 `YYYY-MM-DD`。
- 报表全部实时计算，不落库。
- 删除分类暂不做；如果后续做，历史支出保留 `categoryId`，显示回退为“未分类”。

### 8.3 校验

- `amountCents` 为整数，`0 < amountCents <= 999999999`。
- `content.trim()` 1–80 字。
- `date` 合法且不晚于今天。
- `categoryId` 非空；找不到时按未分类处理。
- `createdAt` / `updatedAt` 有限数字。
- 自定义分类名称 1–20 字，去重（不区分大小写）。

## 9. 报表口径

### 9.1 周期

- 周报：周一 00:00 到周日 23:59，按本地日期。
- 月报：自然月 1 日到月末。
- 当前周期的“未来日期”没有支出，不影响。
- 日均：
  - 已结束周期：总额 ÷ 周期总天数
  - 当前周期：总额 ÷ 已过去的天数（含今天，至少 1 天）
- 周报、月报都显示日均，避免只在大月/小月比较时失真。

### 9.2 总额与笔数

- 总额 = 周期内所有支出 `amountCents` 之和。
- 笔数 = 记录条数。
- 金额显示保留两位小数。

### 9.3 分类占比

- 按 `categoryId` 聚合金额。
- 降序排列。
- 百分比 = 分类金额 ÷ 总额 × 100，四舍五入到整数。
- 前 8 个分类展示，其余合并为 `其他分类 / Other categories`。
- 横条宽度按百分比；最小可见宽度 2%，避免 1% 看不见。
- 自定义分类和预设分类一起统计。

### 9.4 趋势

- 周报：7 天，每天总额；柱子高度按本周最高单日归一化。
- 月报：按 1–7、8–14…聚合为 W1–W5，柱子高度按最高周归一化。
- 点击/触摸柱子，在图表底部显示该周期范围和金额。
- 金额为 0 的日期也保留位置，保持时间轴连续。
- 不做折线图、饼图，减少实现复杂度。

## 10. 视觉与交互

- 金额使用大号、等宽数字（`tabular-nums`），避免跳动。
- 分类占比条使用品牌绿，不同分类用不同透明度/长度区分；不引入彩虹色。
- 流水行：内容 16px 主文字，分类和日期 12.5px 辅助色，金额 16px 半粗。
- 日分组标题 13px，右侧当天小计。
- 汇总卡：总额 24–28px，笔数 12.5px。
- 报表卡片使用 18px 圆角、1px 边框、surface 背景；流水卡片 16px
- 底部导航 4 等分，图标 19px，标签 10.5px。
- 移动端触控目标 ≥ 44px；金额输入和保存按钮要够大。
- 空状态：图标 + 一句说明 + 一个按钮。
- 键盘：金额输入 `inputMode="decimal"`，内容输入普通键盘。
- 所有金额、日期、分类名、报表文案都走 i18n。
- 无障碍：金额和日期字段有 label；删除/编辑有 aria-label；颜色不是唯一状态提示。

## 11. 边界情况

- 0 元、负数、超过两位小数、超大金额。
- 同一天多笔支出、同分类多笔。
- 跨月周（周报包含两个月）。
- 2 月、闰年、月末 31 日。
- 时区变化：按本地日期记，不按 UTC。
- 未来日期禁止。
- 编辑后日期变化，流水分组和报表同步更新。
- 删除最后一笔，报表显示空状态。
- 自定义分类重名、空名、超长。
- 分类数据缺失/损坏时回退“未分类”。
- 大量记录（几百条）：列表滚动正常；报表按周期计算。
- 金额合计精度：全部用分求和，避免 0.1+0.2 问题。

## 14. 待确认的问题

以下是建议默认值，确认后按这个做：

1. **币种**：只做人民币 `¥`，不做多币种。  
2. **只记支出**：第一版不做收入、转账、报销。  
3. **分类管理**：支持新增、删除自定义分类；删除已使用的分类时，二次确认后把支出迁移到“杂项”。改名/排序/图标放到后续。  
4. **预设分类**：按上面的 11 组约 60 个分类；如果你觉得太多，可以删减。  
5. **周起始**：周一。  
6. **日均口径**：当前周期按“已过去天数（含今天）”算，历史周期按完整天数算。  
7. **报表图表**：周报 7 根日柱，月报 W1–W5 聚合柱；点击柱子显示金额；分类用横向占比条，不做饼图。  
8. **删除方式**：左滑删除 + Toast 撤销，不弹确认框。  
9. **未来支出**：禁止。  
10. **收入/预算/多币种/提醒**：第一版不做。

如果这些默认值都同意，我就按 M1 → M4 开始实现。
